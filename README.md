# Kool Vision Marketing — Website

Web design & development showcase site for **Kool Vision Marketing**, a full-service digital marketing agency branch of Kool Vision Media.

## Quick Start

Open `index.html` in a browser. No build step required — pure HTML/CSS/JS.

## Brand Colors

| Role | Hex | RGB |
|------|-----|-----|
| Primary (Teal) | `#43CED6` | `rgb(67, 206, 214)` |
| Dark Text | `#22222A` | `rgb(34, 34, 42)` |
| Muted Text | `#6B7280` | `rgb(107, 114, 128)` |
| Background | `#FFFFFF` | White |
| Light BG | `#F8FAFA` | Off-white |

## Font

**Inter** (Google Fonts) — weights 400, 500, 600, 700, 800, 900.

## Structure

```
index.html      — Main page
styles.css      — All styles (CSS custom properties for brand tokens)
script.js       — Animations, nav, scroll behavior
assets/         — Logo, images (add your files here)
```

## Assets Needed

Drop these into the `assets/` folder:
- `logo.png` — Kool Vision Marketing logo
- `workspace.jpg` — Design workspace photo (for "Design Process" section)
- Portfolio screenshots for the grid

## Deploy

This is a static site. Deploy anywhere: Vercel, Netlify, GitHub Pages, or any web host.
